
# NanoTerm

A minimal standalone Linux terminal for Android.

## Features

- Minimal black and white terminal interface
- Linux userspace without Android root
- Python support
- Bash shell
- Git support
- Internal storage access
- No Termux app dependency

## Project

Name: NanoTerm
Package: com.nanoterm.app
Platform: Android
Language: Kotlin

## Goal

A clean Android terminal that opens directly
into the phone's internal storage.
